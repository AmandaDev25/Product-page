# Teste Técnico - Front-End

Este projeto é uma página web desenvolvida como parte de um teste técnico para front-end. A aplicação exibe informações sobre um produto, incluindo um formulário de cadastro, uma galeria de imagens, um carrossel, depoimentos e um contador regressivo de promoção.

## Tecnologias Utilizadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilização e responsividade.
- **JavaScript (ES6+)**: Interatividade e manipulação do DOM.
- **Bootstrap 5.3**: Layout responsivo e componentes prontos.

## Funcionalidades

- **Formulário de Cadastro:** Permite que os usuários insiram nome, e-mail e telefone para acessar a página do produto.
- **Validação de Dados:** O formulário verifica e-mails e telefones digitados no formato correto.
- **Carrossel de Imagens:** Permite a navegação entre diferentes imagens do produto.
- **Galeria Modal:** Amplia imagens ao clicar sobre elas.
- **Depoimentos de Clientes:** Exibição dinâmica de avaliações.
- **Contador Regressivo:** Mostra o tempo restante para uma promoção.
