# Teste Técnico - Front-End

Este projeto é uma página web desenvolvida como parte de um teste técnico para front-end. A aplicação exibe informações sobre um produto, incluindo um formulário de cadastro, uma galeria de imagens, um carrossel, depoimentos e um contador regressivo de promoção.

## Tecnologias Utilizadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilização e responsividade.
- **JavaScript (ES6+)**: Interatividade e manipulação do DOM.
- **Bootstrap 5.3**: Layout responsivo e componentes prontos.

## Funcionalidades

- **Formulário de Cadastro:** Permite que os usuários insiram nome, e-mail e telefone para acessar a página do produto.
- **Validação de Dados:** O formulário verifica e-mails e telefones digitados no formato correto.
- **Carrossel de Imagens:** Permite a navegação entre diferentes imagens do produto.
- **Galeria Modal:** Amplia imagens ao clicar sobre elas.
- **Depoimentos de Clientes:** Exibição dinâmica de avaliações.
- **Contador Regressivo:** Mostra o tempo restante para uma promoção.

### **Technical Test - Front-End**  

This project is a web page developed as part of a front-end technical test. The application displays information about a product, including a registration form, an image gallery, a carousel, testimonials, and a promotional countdown timer.  

## **Technologies Used**  

- **HTML5**: Page structure.  
- **CSS3**: Styling and responsiveness.  
- **JavaScript (ES6+)**: Interactivity and DOM manipulation.  
- **Bootstrap 5.3**: Responsive layout and pre-built components.  

## **Features**  

- **Registration Form:** Allows users to enter their name, email, and phone number to access the product page.  
- **Data Validation:** The form checks if emails and phone numbers are entered in the correct format.  
- **Image Carousel:** Enables navigation between different product images.  
- **Modal Gallery:** Enlarges images when clicked.  
- **Customer Testimonials:** Dynamically displays user reviews.  
- **Countdown Timer:** Shows the remaining time for a promotion.
